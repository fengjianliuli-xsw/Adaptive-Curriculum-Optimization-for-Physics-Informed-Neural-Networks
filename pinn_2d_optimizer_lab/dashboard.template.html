怎样理解精度与效率
相对 L2 = ‖预测−参考‖₂ / ‖参考‖₂，越低越好。热传导达标率使用绝对温度误差 ≤ 0.05；接触达标率使用位移向量误差 ≤ 0.05 mm。两者不是分类准确率。
切换“实际训练耗时”轴看效率；隐藏 LM 等较慢方法后，可放大其余方法的耗时区间。L-BFGS 有线搜索，LM 有完整残差 Jacobian，多目标方法需要多次反向；残差调用计数不等价于 FLOPs。
训练耗时排除诊断、快照和导出，另存整体运行耗时。所有方法使用固定配置，没有为本次结果做系统超参数搜索；单 PDE / 单种子不能支持普遍优劣结论。
训练使用稀疏固定采样点。独立网格上的场误差与压力分布误差是检验泛化的重要信息，不能只看训练 loss。
