怎样理解“准确率”

连续 PDE 的预测没有天然的分类准确率。这里同时展示两个可解释指标：

相对 L2 = ‖uθ − u*‖₂ / ‖u*‖₂

越小越好；0.01 表示整个评估网格上的相对 L2 误差为 1%。

达标率 = 满足 |uθ − u*| ≤ 0.05 的点数 / 总点数

越高越好。它使用固定绝对容限，真实温度接近 0 时仍有定义；100% 达标不表示解完全精确。

初边值数据包含解析给定的物理条件；内部解析解从未作为训练标签，也未用于选择步长或提前停止。

怎样公平阅读这次实验

所有方法共享 float64 网络、相同初始参数、固定全批采样点、等权总损失和评估网格。每种方法有明示的学习率；本项目没有对各方法做系统超参数搜索。

L-BFGS 外层一次更新可能多次计算损失与梯度；LM 一步需要残差 Jacobian 和线性求解。相同迭代数不等于相同计算成本。耗时仅计入优化步骤，诊断与导出另计；同机顺序运行仍有计时噪声。

残差计算次数统计训练中的损失／残差函数调用，不等价于 FLOPs：构造 Jacobian 和多目标反向传播的成本不同。单 PDE、单随机种子的结果用于教学，不能据此给出通用排名。

方法说明与实现边界
SOAP 是按层稠密实现的教学版本，包含特征基旋转、动量和二阶矩转移，每 10 步更新基，不含 weight decay/grafting。MultiAdam 按论文将 PDE 与初边值分两组，β₁=β₂=0.99。PCGrad 与 ConFIG 直接接普通 GD，避免后接 Adam 再次改变方向。ConFIG 使用伪逆，退化梯度下不承诺严格共同下降。LM 为稠密精确 Jacobian 的教学实现，并利用对偶方程缩小线性系统。详细公式与论文链接见项目 README。
