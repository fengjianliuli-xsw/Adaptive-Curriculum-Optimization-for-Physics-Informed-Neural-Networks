接触由 KKT 条件确定

g ≥ 0，p ≥ 0，pg = 0
φ(g,p) = √(g²+p²) − g − p = 0
g 是变形后到刚性平面的间隙，p 是向上的压应力。Fischer–Burmeister 残差约束非穿透、无拉力与互补性。接触半宽没有写入训练。

标准 Hertz 对照

弹性半圆柱截面用对称性建模为四分之一圆：顶部均匀压力、对称轴位移/剪切条件、圆弧与平面单侧接触。

本例为力控制正问题。载荷是输入，反力平衡是约束核验；不是从未知观测反演合力。FEM 和 Hertz 仅用于评估。

比较方式与实现

每个方法使用同一个网络 state_dict 和相同固定采样。最大步数与训练耗时软预算共同限制，完整一步结束后才停止，因此更新数可能不同。耗时轴是主要效率比较依据。

DCGD-Center：将总梯度投影到两组归一化梯度的角平分线；ConFIG：由归一化梯度伪逆确定公共方向。两者都直接用 GD，不在后面再接 Adam。

两组梯度、相同学习率时，DCGD-Center 与 ConFIG 可给出等价更新。若学习率不同，不能把轨迹差异直接归因于算法。此页每行保留实际学习率。

两组目标为“平衡方程 + 全局虚功”与“边界/接触/载荷约束”。组内各个分项仍可能暂时增加。退化梯度下公共方向可变为零。

参考核验与局限

主动集 FEM 直接满足离散 KKT，不预先指定接触节点。Hertz 是局部半空间近似，与有限半圆柱解有少量差别。压力误差分别相对 FEM 与 Hertz 计算。

主实验采用位移网络，应力通过平面应变本构精确计算；局部平衡残差、全局虚功和 KKT 同时训练。不是原论文的逐行复现。无解析压力或 FEM 场监督。

这是单种子、固定配置与有限预算的探索实验。页面明确保留失败和欠收敛结果，不能据此给出普遍排名。
